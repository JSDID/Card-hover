# Карточка при наведении

## Bootstrap классы, используемые в проекте

- `container` — центрирует и ограничивает ширину контента, добавляет горизонтальные отступы.
- `row` — создает строку для сетки Bootstrap, используется для размещения колонок.
- `m-3` — добавляет внешние отступы (margin) со всех сторон с размером 3.
- `m-auto` — автоматически выравнивает элемент по центру с помощью внешних отступов.
- `col`, `col-12`, `col-sm-12`, `col-md-4` — классы для адаптивной сетки, определяют ширину колонки на разных экранах (12 — вся ширина, 4 — треть ширины на md-экранах).
- `card` — основной контейнер карточки Bootstrap.
- `card-header` — верхняя часть карточки, обычно для заголовка или изображения.
- `card-img-top` — делает изображение верхней частью карточки, растягивает его на всю ширину карточки.
- `mt-3` — добавляет внешний отступ сверху (margin-top) с размером 3.
- `card-body` — основной контент карточки.
- `card-title` — стилизует заголовок внутри карточки.
- `card-text` — стилизует текст внутри карточки.

> Все эти классы позволяют быстро и удобно верстать адаптивные карточки с помощью Bootstrap.
